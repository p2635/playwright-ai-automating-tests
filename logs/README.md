# Logs and Reference Materials

This directory contains raw logs and other reference materials from the learning process.

## Directory Structure

```
logs/
├── README.md (this file)
├── prompt-logs/
│   └── [Saved Claude conversations, prompt history, responses]
│
└── lesson-notes/
    └── [Raw notes from learning specific concepts]
```

## What Goes Where

### prompt-logs/

Store conversations with Claude, prompt iterations, and helpful responses for future reference.

**Example files:**

- `2026-09-21_debugging-flaky-test.md` — conversation about fixing a timeout
- `2026-09-20_page-objects-discussion.md` — Q&A about page object patterns

### lesson-notes/

Quick notes on concepts I'm learning, before they're formalized in `/docs/learning/`.

**Example files:**

- `fixtures-brainstorm.md` — notes on fixture patterns before writing the concept guide
- `locator-strategies-notes.md` — initial notes before creating the locators doc

## How to Use

1. **During learning**: Capture raw logs, screenshots, errors here
2. **After learning**: Synthesize these into curated docs in `/docs/learning/`
3. **For reference**: Link to specific logs when documenting decisions in `/docs/decisions/`
