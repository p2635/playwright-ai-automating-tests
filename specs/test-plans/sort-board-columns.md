# BuggyBoard Sort Board Columns End-to-End Test Plan

- Version: 0.1
- Generated by Claude for Philip Wong on 24 September 2026
- Reviewed by: Philip Wong on 24 September 2026

## Feature Overview

BuggyBoard's board table lets an authenticated user sort bugs by clicking the ID, Severity, Title, or Owner column headers, toggling between ascending and descending order, with only one column sorted at a time.

## Test Scenarios

### 1. Default sort

#### 1.1. Board loads with default sort by Severity descending

**Preconditions:**

1. Authenticate as `buggy`.
2. Bugs exist in the database with severities HIGH, MID, and LOW.

**Steps:**

1. Navigate to the board page.

**Expected Results:**

1. The bugs are displayed in descending severity order (HIGH rows before MID rows before LOW rows). [10-AC1]
2. The Severity column header has `aria-sort="descending"`. [10-AC1]
3. No other column header has an `aria-sort` attribute set. [10-AC1]

### 2. Sorting by a column

#### 2.1. Clicking the Title column header sorts ascending on first click

**Preconditions:**

1. Authenticate as `buggy` and open the board.
2. At least two bugs exist with distinct titles.

**Steps:**

1. Click the Title column header.

**Expected Results:**

1. The Title column header has `aria-sort="ascending"`. [10-AC2]
2. The visible bug titles are in ascending alphabetical order. [10-AC2]
3. Only the Title column header has an `aria-sort` attribute set. [10-AC2]

#### 2.2. Clicking the Title column header again toggles to descending

**Preconditions:**

1. Authenticate as `buggy` and open the board.
2. At least two bugs exist with distinct titles.
3. The Title column has been sorted ascending.

**Steps:**

1. Click the Title column header again.

**Expected Results:**

1. The Title column header has `aria-sort="descending"`. [10-AC3]
2. The visible bug titles are in descending alphabetical order. [10-AC3]

#### 2.3. Sorting a new column clears the previous column's indicator

**Preconditions:**

1. Authenticate as `buggy` and open the board.
2. At least two bugs exist with distinct owners and severities.
3. The Owner column has been sorted (so it shows a sort indicator).

**Steps:**

1. Click the Severity column header.

**Expected Results:**

1. The Severity column header has an `aria-sort` attribute set. [10-AC4]
2. The Owner column header no longer has an `aria-sort` attribute. [10-AC4]
3. The bugs are ordered by severity only. [10-AC4]

## Technical Information

### Seed / Fixture Guidance

Use `tests/seed.spec.ts` as the Playwright seed. Create bugs via `tests/support/board-fixtures.ts` (`createBug`) with distinct, known titles/owners/severities/IDs so ordering can be asserted deterministically; use `deleteAllBugs` or per-test `deleteBugIfExists` cleanup so default data does not affect ordering assertions.

### Locator Guidance

Reuse `tests/pages/board.page.ts`: `titleColumnHeader`, `severityColumnHeader` (extend with `idColumnHeader` / `ownerColumnHeader` locators via `getByRole('columnheader', { name: ... })`), and `visibleTitles()` / `visibleSeverities()` helpers (add analogous `visibleIds()` / `visibleOwners()` helpers reading `tbody tr td:nth-child(1)` / `:nth-child(4)`). Column header buttons are `getByRole('button', { name: 'ID' | 'Severity' | 'Title' | 'Owner' })`. Assert sort direction via `columnheader.getAttribute('aria-sort')` rather than the visual arrow glyph.
