# BuggyBoard Create Bug End-to-End Test Plan

- Version: 0.1
- Generated by Phil on 22 September 2026
- Reviewed by Phil: Version 0.1 reviewed 22 September 2026

## Feature Overview

BuggyBoard's Create bug dialog lets an authenticated user add a new bug from the board's title bar.

## Test Scenarios

### 1. Create bug workflow

#### 1.1. Opens the create-bug modal with required controls

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Click the "New Bug" button in the title bar.

**Expected Results:**

1. A dialog named "Create bug" is visible. [06-AC1]
2. The dialog contains labeled Title, Severity, Owner, and Description controls. [06-AC1]
3. The dialog contains Cancel and Save buttons. [06-AC1]
4. The Severity control offers HIGH, MID, and LOW options. [06-AC1]

#### 1.2. Defaults owner to the authenticated user

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Open the Create bug dialog.

**Expected Results:**

1. The Owner field value is "buggy". [06-AC2]
2. The Title field is focused and empty. [plan-only]
3. The Severity field defaults to MID. [plan-only]

#### 1.3. Saves a valid bug and closes the modal

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Open the Create bug dialog.
2. Fill Title with a unique title, select HIGH in Severity, keep Owner as buggy, and fill Description with valid text including special characters such as < and >.
3. Click Save.

**Expected Results:**

1. The Create bug dialog is visible after opening. [06-AC1]
2. The entered values remain in their respective controls before saving. [plan-only]
3. The dialog is closed. [06-AC3]
4. A board row shows the unique title, HIGH severity, and buggy owner. [06-AC3]

#### 1.4. Cancels without saving

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Open the Create bug dialog and enter a unique title.
2. Click Cancel.

**Expected Results:**

1. The entered title is visible in the dialog before cancelling. [plan-only]
2. The dialog is closed. [06-AC4]
3. No board row shows the unique title. [06-AC4]

#### 1.5. Closes with the X button without saving

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Open the Create bug dialog and enter a unique title.
2. Click the Close button in the upper-right corner.

**Expected Results:**

1. The entered title is visible in the dialog before closing. [plan-only]
2. The dialog is closed. [06-AC5]
3. No board row shows the unique title. [06-AC5]

#### 1.6. Closes with Escape without saving

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Open the Create bug dialog and enter a unique title.
2. Press Escape.

**Expected Results:**

1. The entered title is visible in the dialog before closing. [plan-only]
2. The dialog is closed. [06-AC6]
3. No board row shows the unique title. [06-AC6]

#### 1.7. Keeps entered data when the backdrop is clicked

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Open the Create bug dialog and enter a unique title and description.
2. Click the dimmed backdrop outside the dialog panel.

**Expected Results:**

1. The entered values are visible in the dialog before clicking the backdrop. [plan-only]
2. The dialog remains open. [06-AC7]
3. The title and description values are preserved. [06-AC7]

#### 1.8. Blocks save when required fields are blank

**Preconditions:**

1. Authenticate as `buggy` and open the board.

**Steps:**

1. Open the Create bug dialog without filling any fields.
2. Click Save.

**Expected Results:**

1. The dialog is visible after opening. [06-AC1]
2. The dialog remains open. [06-AC8]
3. An alert lists required-field validation messages. [06-AC8]
4. No new bug is added to the board. [06-AC8]

## Out of Scope (deferred)

- Per-field blank validation (title, severity, owner, description individually left blank, per the Scenario Outline in `specs/features/06-create-bug.md`) is not covered as separate scenarios; only the combined "all fields blank" case (1.8) is tested. To be addressed in a future revision of this plan.

## Technical Information

### Seed / Fixture Guidance

Use `tests/seed.spec.ts` as the Playwright seed for every workflow. It authenticates as the `buggy` user and verifies navigation to `/board`.

### Locator Guidance

Prefer accessible Playwright locators: `getByRole('dialog', { name: 'Create bug' })`, `getByRole('button', { name: 'New Bug' })`, labeled Title/Severity/Owner/Description controls, and `getByRole('button', { name: 'Save' })` / `'Cancel'` within the dialog. Use board row text for created-bug identity.
