## Application Overview

BuggyBoard is a web-based bug tracker. An authenticated user reaches the board and opens a bug's Edit modal by clicking its row. The Edit modal shows ID, Title, Severity, State, Owner, and Description, plus a "Delete" button alongside Cancel and Save. Clicking Delete removes the bug immediately (no confirmation prompt): the modal closes and the board table no longer shows that row. The Delete button is available for bugs in both the Open and Closed state.

## Seed / Fixture Guidance

Use `tests/seed.spec.ts` as the Playwright seed for every workflow. It authenticates as the `buggy` user and verifies navigation to `/board`.

Each scenario must create the bug(s) it deletes as part of its own setup, via the backend REST API (`POST http://localhost:3000/api/bugs`, matching the `BugFixture` shape and `seedBoardFixtures` helper in `tests/support/board-fixtures.ts`), so every test starts from a known, isolated bug rather than relying on pre-existing board data. Use a unique title per test (e.g. via a timestamp or random suffix) to avoid collisions between parallel runs. Do not delete or reset unrelated bugs already on the board.

## Test Scenarios

### 1. Delete bug workflow

**Seed:** `tests/seed.spec.ts`

#### 1.1. edit modal shows a delete button

**File:** `tests/delete-bug/delete-bug.spec.ts`

**Steps:**

  1. Create an Open bug named with a unique title via the API, then open the board and click its row to open the Edit modal.
    - expect: The "Edit bug" dialog is visible.
    - expect: The dialog shows a "Delete" button.
    - expect: The dialog also shows "Cancel" and "Save" buttons.

#### 1.2. deletes an open bug and closes the modal

**File:** `tests/delete-bug/delete-bug.spec.ts`

**Steps:**

  1. Create an Open bug with a unique title via the API, then open the board and click its row to open the Edit modal.
    - expect: The "Edit bug" dialog is visible with the bug's title.
  2. Click Delete.
    - expect: The dialog is closed.
    - expect: No board row shows the deleted bug's title.
    - expect: A GET to the bugs API no longer includes the deleted bug's ID.

#### 1.3. deletes a closed bug and closes the modal

**File:** `tests/delete-bug/delete-bug.spec.ts`

**Steps:**

  1. Create a Closed bug with a unique title via the API, switch the board to the "Closed" filter, then click the bug's row to open the Edit modal.
    - expect: The "Edit bug" dialog is visible with the bug's title and State set to "Closed".
  2. Click Delete.
    - expect: The dialog is closed.
    - expect: No board row under the "Closed" filter shows the deleted bug's title.

#### 1.4. deleted bug does not reappear after reload

**File:** `tests/delete-bug/delete-bug.spec.ts`

**Steps:**

  1. Create an Open bug with a unique title via the API, open its Edit modal, and click Delete.
    - expect: The dialog is closed and the bug is removed from the board.
  2. Reload the page.
    - expect: No board row shows the deleted bug's title.

#### 1.5. cancel does not delete the bug

**File:** `tests/delete-bug/delete-bug.spec.ts`

**Steps:**

  1. Create an Open bug with a unique title via the API, then open its Edit modal.
    - expect: The "Edit bug" dialog is visible with the bug's title.
  2. Click Cancel without clicking Delete.
    - expect: The dialog is closed.
    - expect: The board still shows a row with the bug's title.

#### 1.6. deleting one bug leaves other bugs on the board

**File:** `tests/delete-bug/delete-bug.spec.ts`

**Steps:**

  1. Create two Open bugs, each with a unique title, via the API. Open the Edit modal for the first bug.
    - expect: The "Edit bug" dialog is visible with the first bug's title.
  2. Click Delete.
    - expect: The dialog is closed.
    - expect: No board row shows the first bug's title.
    - expect: A board row still shows the second bug's title.
